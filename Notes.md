\# **Network Reconnaissance Notes**



* Objective



Perform basic reconnaissance against Metasploitable 2.



* Tool



Nmap 7.99



* Command



nmap 192.168.59.128



* Findings



\- Host is reachable.

\- 23 TCP ports are open.

\- Multiple services including FTP, SSH, HTTP, SMB, MySQL, PostgreSQL, and VNC were identified.



* Learning Outcome



Learned how to identify live hosts and enumerate open TCP services using Nmap.
