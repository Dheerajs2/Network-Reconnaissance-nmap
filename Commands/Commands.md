# Commands Used

## Check IP Address

```bash
ip addr
```

---

## Ping Test

```bash
ping 192.168.59.128
```

---

## Basic Scan

```bash
nmap 192.168.59.128
```

---

## Version Detection

```bash
nmap -sV 192.168.59.128
```

---

## OS Detection

```bash
sudo nmap -O 192.168.59.128
```

---

## Aggressive Scan

```bash
sudo nmap -A 192.168.59.128
```
